# استبدال الموقع القديم بموقع Portfolio الجديد

رابطك يبقى كما هو:

**https://aimanrkil8-ui.github.io/my-website/**

لا تحتاج تغيير اسم المستودع — فقط استبدل الملفات داخل `my-website`.

---

## الطريقة 1 — من GitHub (بدون برامج)

1. افتح: https://github.com/aimanrkil8-ui/my-website
2. احذف الملفات القديمة (أو كل الملفات ما عدا `.git` إن وجد)
3. اضغط **Add file** → **Upload files**
4. اسحب **كل** محتويات مجلد Portfolio الجديد:
   - `index.html`
   - مجلد `css/`
   - مجلد `js/`
   - مجلد `assets/` (مع صور mmm, nnnn, bbbb)
   - `sitemap.xml`, `robots.txt`, `.nojekyll`
5. **Commit changes**
6. انتظر 1–3 دقائق وافتح الرابط

---

## الطريقة 2 — من PowerShell (Git)

### أ) أول مرة — استنساخ المستودع القديم

```powershell
cd C:\Users\BBG\Documents
git clone https://github.com/aimanrkil8-ui/my-website.git
cd my-website
```

### ب) نسخ الموقع الجديد فوق القديم

```powershell
# احذف كل الملفات القديمة ما عدا .git
Get-ChildItem -Force | Where-Object { $_.Name -ne '.git' } | Remove-Item -Recurse -Force

# انسخ الموقع الجديد
Copy-Item -Path "C:\Users\BBG\.cursor\projects\empty-window\aiman-portfolio\*" -Destination . -Recurse -Force
```

### ج) رفع التحديث

```powershell
git add .
git commit -m "Replace old site with new bilingual portfolio"
git push origin main
```
